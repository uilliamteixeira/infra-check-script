# 🛠️ Infra Check Script

Script simples em PowerShell para verificar o status de serviços essenciais em máquinas Windows.

## Serviços monitorados
- Spooler (impressão)
- Windows Update
- Windows Defender

## Como usar
1. Execute o script com permissões de administrador
2. Verifique o arquivo `status_log.txt` gerado na mesma pasta
